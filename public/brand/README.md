# HH Goa placeholder brand kit

The generator and canvas renderer read campaign assets from this directory so the official kit can be swapped without restructuring the app.

- `hh-goa-wordmark.svg` — primary placeholder wordmark
- `hacker-house.png` — supplied Hacker House title art
- `goa-hindi.svg` — supplied Goa lettering
- `sunrise.png` — supplied Goa sunrise illustration
- `sunrise-ui.webp` — optimized interface copy of the sunrise illustration
- `patterns/` — lightweight decorative SVG accents

Keep replacement files at the same paths, or update the centralized paths in the renderer and interface.
